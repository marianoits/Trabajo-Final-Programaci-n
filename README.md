# Sistema de Autogestión de Asistencia

Proyecto final de Programación II, desarrollado en Python utilizando Programación Orientada a Objetos (POO).

# Archivos del proyecto

* "modelos.py" : Clases (`Estudiante`, `Materia`, `Clase` y `Asistencia`).
* "gestor_sistema.py" : Gestión de datos, casos de uso y ordenamiento alfabético por apellido mediante `QuickSort`.
* "main.py" : Menú con datos de prueba cargados.
* "test_sistema.py" : Pruebas con `unittest` para validar clases y casos de uso.
